# **App Name**: ReunionStats

## Core Features:

- Member Management: Add, remove, or modify team members.
- Role Assignment: Select a presenter and secretary for each meeting.
- Secretary Selection AI Tool: AI tool to suggest the next secretary based on a fairness algorithm that considers how frequently each member has volunteered or presented. Supports both random selection and volunteer selection.
- Meeting Agenda: Create a meeting agenda with topics and estimated times.  Supports ad-hoc addition and removal of topics.
- Meeting Timer: A timer for each agenda item to track the actual time spent.
- Statistic Calculations: Automatically calculate and store meeting statistics and history, based on provided KPIs.
- Historical View: View meeting history and statistics over time.

## Style Guidelines:

- Primary color: Light, professional blue (#6699CC) for trustworthiness and stability.
- Background color: Soft, desaturated blue (#E6EEF2), visibly similar in hue to the primary color but lightly desaturated to provide a clean backdrop.
- Accent color: Analogous teal (#367588) to complement the primary blue.
- Font pairing: 'Inter' (sans-serif) for body text and 'PT Sans' (sans-serif) for headers, ensure legibility and a modern feel.
- Use simple, clear icons for navigation and key actions.
- Clean and structured layout to prioritize readability.
- Subtle transitions for feedback, and focus, with minimal distraction.
